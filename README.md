# Dynamics of coral supply and benthic structure in the Northern Great Barrier Reef, Australia

## Monique J. White


These files are written by Monique J White,
for the thesis component of a Masters in Marine Biology at James Cook University.


Coralsettlement_nGBR_CS.xlsx is the original data file provided from Andrew Hoey.

Data from benthic and belt transects were provided by Andrew Hoey in the file "Cross-shelf benthic surveys_2013-25_nGBR.csv"
however, I made these into two individual csv files, including only relevant years, named:
1. Belt_10m_final.csv

2. PIT_final.csv

## Rmarkdowns for data analysis

02_Model_selection: provides all code to making models, 
and choosing the best performing models

03_Figures: provides the code used to generate figures, 
based on best performing models outlined in the 02_Model_selection

04_Tables: provides the code to generate tables,
based on best performing models outlined in the 02_Model_selection


## Note
